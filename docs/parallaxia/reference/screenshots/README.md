## `p47_3l.gif` に写っているもの

- 黒い背景。中央の縦長の領域がフィールドで、左右は情報パネル
- 左のパネル: 上にモードを示す文字、その下に縦に並んだ得点。右のパネル: 上に残機、下にパーセクの数値。数字は白い角ばった線の文字
- フィールドの背景: 青い線の四角い枠が奥へ向かって重なり、トンネルのように見える
- 上端: 赤と白の線で描かれた大きな敵
- 赤い縁の三角形の敵弾が、上から扇状に降ってきている
- 緑の小さな四角のかたまり（アイテム）が多数、フィールドの中ほどから下に漂っている
- 下端の中央: 自機。そこから黄色い線のショットが真上へ伸びている
- 自機の周りに、白い線の四角がいくつか回っている（ロールショット）
- 全体に細い線だけで描かれ、塗りはほとんどない
