# 原作の弾幕の構成

原作の弾幕は BulletML の XML で書かれ、13 のディレクトリに分かれている。
ここでは、どんな部品があり、どう組み合わされるかを説明する。個々の XML は写していない。

- 根拠: `original/p47_0_21/p47/` の各弾幕ディレクトリと `src/abagames/p47/`（EnemyType, Enemy, BulletActorPool, MorphBullet, BarrageManager）
- 原作の XML をリメイクで使うかどうかは未決定である（`docs/remake-decisions.md`）

## 部品の分類

| 分類 | 数 | 役割 |
| --- | --- | --- |
| small / small_lock | 各 1 | 小型の敵の弾。自機狙いの単発を、間を置いて撃つ |
| middle | 10 | 中型の本体の弾幕。ボスの翼の砲台にも使う |
| middlesub / middlesub_lock | 各 1 | 中型・大型の翼の砲台の弾。自機狙いの短い連射 |
| large | 14 | 大型の本体と、ボスの本体の弾幕 |
| morph / morph_lock | 各 15 | 「弾が変化する先」の弾幕（後述） |
| smallmove / smallsidemove | 15 / 4 | 小型の敵の動き |
| middlemove / middlebackmove | 5 / 1 | 中型の敵の動き（backmove は使われていない） |
| largemove | 2 | 大型の敵の動き |

`_lock` が付くものは LOCK モード用で、同じ名前の ROLL 用と比べて弾数や間隔が調整されている。

## 組み合わせ方

敵の「型」が作られるとき（1 ステージに 1 回）、次が乱数で決まる。

1. **本体の弾幕**: その種類用の分類から 1 つ選ぶ
2. **翼の砲台の弾幕**: 中型・大型は middlesub、ボスは middle から 1 つ選ぶ。左右は鏡像
3. **ランクの配分**: ステージのランクを、本体と翼にどう分けるか。「本体だけ」「翼だけ」「両方に半分ずつ」のような数通りから選ぶ。
   配分が 0 の側は撃たない
4. **変化の連鎖**: 弾幕ごとに morph から重複なしで並びを作る
5. **見た目**: 弾の形・色・大きさ、左右反転の向き

同じ分類の部品でも、ランクの配分と変化の連鎖で別物になる。これが「毎回違う弾幕」の出どころである。

## 弾の変化（morph）

原作の弾幕の特徴はここにある。

- 本体の弾幕が撃つ「弾」は、変化の段数が残っていれば、ただの弾ではなく **morph の弾幕を実行する発射元** になる
- 発射元は、自分の向きと速さを基準に、いくつかの弾を撃って消える（または撃ち続ける）
- 撃たれた弾にも段数が残っていれば、連鎖の次の morph を実行する。段数が尽きると普通の弾になる

たとえば「全方位に 8 発」の本体に「3 方向に分かれる」「速度差をつけて縦に並ぶ」を 2 段重ねると、
8 方向それぞれが 3 つに分かれ、さらにそれぞれが縦列になる。
段数はランクから決まるので、ランクが上がると弾幕は「濃くなる」のではなく「構造が増える」。

### morph の部品の傾向

名前と記述から読み取れる範囲の分類である（動かして確かめてはいない）。

| 傾向 | 部品の例 | 起きること |
| --- | --- | --- |
| 方向に分かれる | 3way, nway, wide, sideway, spread, divide | 元の向きを中心に左右へ分かれる |
| 速度差で列になる | bar, accel, 248shot | 同じ向きに速度の違う弾を並べる |
| 途中で向きを変える | 6gt, twin | 横へ出てから進行方向へ曲がる |
| 減速して撃ち直す | slowdown, fire_slowshot, kr1b_bit_shot, side_back_shot | 止まる・遅くなる・後ろへ撃つ |

多くは `$rank`（弾数ランク）で分かれる数や列の長さが変わる。

## 本体の弾幕の傾向

| 分類 | 傾向 |
| --- | --- |
| middle | 回転しながら撃つもの（roll2way, roll4way, nwroll, double_roll_seeds）、輪を繰り返すもの（2round, 4way）、自機狙いの散弾（shotgun）、ボス由来のもの（dr1_boss_3, kr3_boss_fastspread, spread_bf） |
| large | 扇を重ねるもの（57way, nway, mnway, wide_spread, forward_3way）、全方位（allround, growround, 88way）、数が増えていくもの（grow）、乱数の速度でばらまくもの（pxa_boss_opening, spread2blt）、ボス由来のもの（dr1_boss_1, dr1_boss_2, kr4_boss_rb_rockets） |

- 自機狙い・固定方向・前の弾からの相対角（少しずつ回る）を使い分けている
- ほぼすべてが `$rank` で弾数か待ち時間を変える。乱数を使うものは一部
- 1 つの XML に複数の発射系列があり、同時に走るものがある

## 敵の動き

敵は「見えない弾」として、移動用のパターンで動かされる。

| 分類 | 傾向 |
| --- | --- |
| smallmove | 降りてきて止まり引き返す、自機の方へ曲がる、加速して抜ける、横へ流れる、など |
| smallsidemove | 横から入って直進、加速しながら上または下へ抜ける、自機を追う |
| middlemove | 降りるだけ（速度 3 段階）、曲がる、降りて止まり引き返す |
| largemove | 降りるだけ（速度 2 段階） |

小型は動きで変化を出し、中型・大型は動かずに弾幕で変化を出す、という役割分担になっている。

## リメイクで決めること

- 弾幕の記述に BulletML を使うか。使うなら原作の XML を流用するか（候補のライブラリは `research/bulletml-js.md`）
- 「型をランダムに作る」「弾が変化する」という構造を踏襲するか
- 使っている BulletML の要素は action, fire, bullet, repeat, wait, changeDirection, changeSpeed, accel, vanish と、その参照（`*Ref`）、変数 `$rank` `$rand` `$1` 等である。
  独自に実装する場合の範囲の目安になる
