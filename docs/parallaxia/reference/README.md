# reference/ — 制作の一次資料

制作エージェントが読んでよい資料である。原作（`original/`）を開く代わりに、まずここを読む。

| ファイル | 中身 |
| --- | --- |
| `overview.md` | 著者による紹介文、操作方法、起動オプション、更新履歴、プレイ動画の URL |
| `mechanics.md` | 原作の仕様メモ。挙動と数値 |
| `barrage.md` | 原作の弾幕の構成（部品の分類と組み合わせ方） |
| `screenshots/` | 著者のページにある画面写真 2 枚の説明（画像そのものは公開していない。取得元は説明にある） |

## 書き方の規則

- 挙動、設計意図、数値、実測値は書く
- 原作のコードは貼らない。クラス構成・ファイル構成・処理順をなぞった説明も書かない
- 各文書の冒頭に、根拠にした原作側のファイルを書く
- 確かめていないことは「未確認」と書く

必要な事実がここに無いときは、その事実だけを `original/` で調べ、ここに追記してから使う。
