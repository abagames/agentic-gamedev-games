# リメイクとして著者が決めること

決まったら「決定」の欄に書き、`docs/spec-draft.md` の該当箇所を直す。
「制作前」の欄に ◎ が付いたものは、最初のタスク（自機の移動）に入る前に決めておきたい項目である。
◯ は、その項目に当たるタスクの前までに決めればよい。

## 回答済み（2026-10-08）

- タイトル画像（`title.bmp`）も著者の自作である
- ver. 0.2 と 0.21 の違いは SDL の更新だけである（0.2 を元にした M-HT フォークや Debian 版は、遊びの面では 0.21 と同じとみなせる）

- 意図的な処理落ちと弾の出現演出は、リメイクに必須ではない
- アイテムを画面の下端で拾えること、回転中のロールで敵を削れることは、どちらも意図した仕様である

- 全体の構成を決めた（2026-10-10、著者）: 無限 SECTOR 制。現状を標準とし、敵弾が速く密度が低いモード、敵弾が遅く密度が高いモードの 3 つを選べる。10 SECTOR ごとの開放は、どのモードでもできる。モードごとに自機の速さを変える（敵弾が速ければ自機も速く、遅ければ自機も遅くして精密に避けられるように）。現在の自機は少し速すぎるかもしれない。モードと SECTOR ごとの固定は段階 2。バランスは適切に調整する

- SECTOR の開放はモードで共通にする。あるモードで難しすぎる SECTOR があっても、他のモードで先に進めるようにしたい（同、著者の指示）
- 編隊全滅ボーナスをやめ、得点倍率にする（2026-10-10、著者の決定）。全滅させるたびに倍率が 1 増え、最大 x16、逃がすと x1。これは RAPID 向けの規則で、NORMAL は敵への接近度合いで x1〜x16、DENSE は敵弾にかすると倍率が上がり時間で下がる、とモードごとに分ける
  - エージェントが置いたもの: 倍率を掛ける範囲（撃破の点数すべて）、NORMAL の距離（3 以内で x16、13 以上で x1）と上端の除外（y 12 より上は x1）とレーザーの扱い（放った瞬間の距離）、DENSE の値（半径 1.2、+0.4、1.5 秒後から 1 秒に 1 ずつ減る）と島の見返り（5 秒止まる）、ボスの点数の引き下げ、モード別のエクステンド
