# モバイル向けの操作

> **決定（2026-10-08）**: ロックオンは案 A（ためて離して放つ）。モバイルは片手（1 本指）を優先。PC とモバイルは同じ遊び。PC のショットはオートにしない。
>
> 実装した形: ショットを押している間（タッチでは触れている間）にロックがたまり、離すと発射する。規則は PC とモバイルで同じである。
> 仕様は `docs/spec-draft.md` §4 にある。下は決める前の検討の記録である。
>
> **残っている違い**: タッチでは、指を離すと自機も止まる。キーボードでは、ショットを離しても動き続けられる。
> 同じ規則でも、発射の瞬間の危険はタッチのほうが大きい。揃えるなら「発射した瞬間は誰でも短時間動けない」のような規則が要るが、入れていない。
> 著者の決定（2026-10-08）: この差は揃えない。スローは無くした（2 本目の指の操作も無い）。


著者の要望（2026-10-08）: オートショット、オートロック（離してリリース）のモバイル向け操作を考えたい。

決定ではない。案と、いま試せる試作と、決めるべき点をまとめている。

## いま試せる試作

指（またはマウス）で操作できる。スマートフォンのブラウザで開くか、PC ではマウスのドラッグで試せる。

| 操作 | 動き |
| --- | --- |
| 画面のどこかをドラッグ | 指の「動いた分」だけ自機が動く（指の位置へ飛ぶのではない）。触れている間はショットが出続ける |
| 2 本目の指を置く | スロー |
| 指を離す | 自機が止まり、ショットも止まる |

- 自機の最高速度はキーボードと同じである。指を速く動かすと、自機が遅れて追いつく。**高速移動の上限を守るため**にこうしている。
  指に完全に追従させると、自機の速度に上限が無くなり、「速い通常移動と遅いスロー」という遊びの軸が消える
- 端に当たったあと、指を戻した分だけすぐ自機も戻る（余分に引きずった距離は捨てている）
- 仕組みとしては、指の動きをキーボードと同じ入力（上下左右・ショット・スロー）に変換しているだけである。
  シミュレーションとリプレイは、指かキーかを区別しない。キーボードと指で別の強さのゲームにならない

確かめたのは、ヘッドレスのブラウザでのマウス操作だけである。**実機の指では試していない**（追従の遅れの感じ、指で自機や弾が隠れる問題は未確認）。

## ロックオンの案

ロックオンレーザーはまだ実装していない（この文書を書いた時点。そのあと実装した）。モバイルと PC で同じ遊びにするか、分けるかを先に決めたい。

### 案 A: 触れている間に自動でロックし、指を離すと発射する

著者の言う「オートロック（離してリリース）」をそのまま形にしたもの。

- 触れている間: 移動＋オートショット。前方の中型以上の敵に、一定の間隔で自動的にロックがかかる（最大 4）
- 指を離す: ロックした数だけレーザーを発射する。離している間は自機が止まる
- 遊びの形: **「いつ止まるか」が判断になる。** 撃つには動きを止めなければならないので、弾の切れ目を読んで離す
- スローは無くなる（ボタンが足りない）。精密に避けたいときは指をゆっくり動かせばよいので、モバイルではスローの必要が薄い
- 気がかり: 原作のロックは「押している間ずっと撃ち続ける」攻撃で、こちらは「ためて放つ」攻撃になる。
  原作ではロールショットに近い手触りである。モードを LOCK だけにした決定とは両立するが、火力の出方は別物になる
- 気がかり: 指を離すと自機が止まるので、弾幕の中では離しにくい。レーザーの発射中に短い無敵を付ける、などの補いが要るかもしれない

### 案 B: 触れている間ずっと自動でロックして撃つ

- 触れている間: 移動＋オートショット＋前方の敵へ自動でロックして撃ち続ける
- 指を離す: 止まるだけ
- 遊びの形: 判断は位置取りだけになる。敵の正面に入れば勝手に大きな火力が出る
- 気がかり: 押す・離すの判断が消えるので、「何も判断しなくても強い」に近づく。方策比較で、動くだけの方策との差が縮むはずである
- 原作のロックは「スロー中だけ」という代償があった。その代償が無くなる

### 案 C: 2 本目の指でスロー＋ロック（原作と同じ意味）

- 1 本目: 移動＋オートショット。2 本目を置いている間: スロー＋ロックオンして撃ち続ける
- 遊びの形: 原作と同じ。「遅くなる代わりに大物への火力が出る」
- 気がかり: 片手で遊べない。スマートフォンを片手で持って親指 1 本、という遊び方ができなくなる
- いまの試作はこの形に進める（2 本目の指がすでにスローになっている）

### PC との関係

| | PC（キーボード、ゲームパッド） | モバイル |
| --- | --- | --- |
| 案 A を PC にも適用 | スローを押すとロックをため、離すと発射。ショットは押している間（またはオート） | 触れてため、離して発射 |
| 案 C を両方に適用 | 原作どおり | 2 本指 |
| PC は原作どおり、モバイルだけ案 A | 遊びが 2 種類になる。得点を比べられなくなり、調整も 2 倍になる | |

**見立て**: PC とモバイルで同じ遊びにするほうがよい。調整と検査が 1 本で済み、リプレイも共通になる。
そのうえで案 A を両方に採るなら、PC では「スローを押している間、遅くなってロックがたまり、離すと発射」となり、
原作のロールショットの手触り（ためて放つ）をロックオンで再現する形になる。スローの代償（遅くなる）も残る。
モバイルでは「触れている＝通常」「離す＝発射して停止」とすると、PC とは代償の形が違ってしまうので、
モバイルでも 2 本目の指を「ため」に使う（置くとスロー＋ロックがたまる、離すと発射）ほうが PC と揃う。
片手操作を優先するなら、揃えるのを諦めて案 A をそのまま採ることになる。

## オートショット

- モバイルは、触れている間ずっと撃つ（試作のとおり）。ボタンを置く場所が無いので、これ以外は難しい
- PC もオートにするかは別の判断である。いまの決定（`docs/remake-decisions.md` の B4）は「押している間だけ出る」。
  原作では、ショットを止める理由がほとんど無い。PC もオートにすると、ボタンはスロー 1 つだけになる

## 決めてほしいこと

1. ロックオンは「撃ち続ける」（原作）か、「ためて離して放つ」（案 A）か
2. モバイルは片手（1 本指）で遊べることを優先するか
3. PC とモバイルで同じ遊びにするか
4. PC のショットもオートにするか

1 が決まれば、T6（中型の敵とロックオンレーザー）に入れる。
