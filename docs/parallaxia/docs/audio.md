# 音

building-era-authentic-game-audio の手順に沿って作った。**時代風（era-inspired）であり、特定の基板の再現ではない。**
人の耳での確認は、効果音も BGM も、まだしていない。

## 決めたこと

| 項目 | 内容 |
| --- | --- |
| 方式 | 手続き的に生成する（著者の決定）。Web Audio の発振器とノイズだけで、音声ファイルは無い |
| 音源の枠 | 4 声。矩形波 2（pulse1、pulse2）、三角波の低音 1（bass）、ノイズ 1（noise）。どの声も同時に 1 音 |
| 音の作り | 一定の音量で鳴って切れる音と、直線的な音程の変化だけ。エフェクトなし、モノラル |
| 全体の音量 | 効果音 0.24、BGM 0.34。いちばん大きい効果音の組み合わせを、いちばん大きい曲の上で鳴らしても、最大 0.76 で、振り切れない（検査している） |
| BGM | **ある**（2026-10-11、著者の指示）。効果音とは別の音源として、ファミコンの 5 チャンネルの枠で鳴らす（下の「BGM」）。以前は「無い」としていた |
| 同じフレームの衝突 | 優先度の高い音から声を取る。取れなかった音は鳴らさない（drop）。同じ名前の音は 1 フレームに 1 回まで |
| 声の取り合い | 鳴っている音より優先度が低い音は、その声が空くまで鳴らない。同じか高ければ取って代わる |
| 新しい run | 声の占有はシミュレーションのフレームで数えるので、シミュレーションを作り直すとき（再スタートなど）に、鳴っている効果音を止めて声を空ける。空けないと、前の run のゲームオーバーの音が、新しい run の音を全部 drop させる |
| 画面が隠れたとき | 鳴っている音を止め、出力を休止する。戻っても、隠れている間の音は鳴らし直さない |
| 消音 | M キーで効果音も BGM も全部。選択はブラウザに保存する。BGM だけを切る B キーは、著者の決定で無くした（2026-10-11） |
| ポーズ | P キー。ゲームと一緒に音も止まり、再開すると曲は同じところから続く |
| 最初の音 | ブラウザの制約で、キーを押すか画面に触れるまで音は出ない。ゲームパッドだけで始めた場合、音が出ないことがある（未確認） |

## BGM（2026-10-11）

著者の指示: ベースがしっかりしていて、ドラムが入っていて、疾走感のある曲。2 つの音源をユニゾンさせてわずかにずらし、うねりで熱く広がって聞こえるパート。発音のタイミングを少しずらして、ダブリングやコーラスに近い効果を得る箇所。DPCM のドラム。制約の範囲内でファミコンの音源を活かす。場面ごとに、エレクトロニカ・テクノから合うジャンルを選ぶ。

**ファミコン風（Famicom-inspired）であり、エミュレーションではない。** 曲のデータは `src/audio/music.js`、再生は `src/audio/musicplayer.js`、検査は `test/music.test.mjs` と `tools/audio.mjs`。

### 守っている制約

| チャンネル | 制約 |
| --- | --- |
| 矩形波 1・2 | デューティ比 3 種（12.5%、25%、50%）、音量 16 段、同時に 1 音。音程は、実機と同じ「タイマーの周期（整数）」で決める |
| 三角波 | 音量は 1 つだけ（鳴るか鳴らないか）。波形は 32 段の階段。c2（65 Hz）より下は使わない |
| ノイズ | 音程 16 種、音量 16 段 |
| DPCM | 1 ビットの差分で波形を追い（1 サンプルに 2 段ずつ上下）、7 ビットで出す。同時に 1 つ。キックとスネアを、この方式で作った波形で鳴らす |
| 更新 | 何も、1 フレーム（60 分の 1 秒）より細かくは変わらない |

**実機と違う点**: 効果音は、この 5 チャンネルを奪わない。効果音には、これまでの 4 声が別にある（合わせて 9 声）。実機なら、ショットの音が矩形波を 1 つ奪い続け、ユニゾンのうねりが、撃っている間ずっと消える。
このゲームはほぼ常に撃っているので、曲の聞かせどころを残すために分けた。音源を 2 つ積んだ業務用基板、という見立てである。

### 使っている技法

| 技法 | 中身 | 使っている場所 |
| --- | --- | --- |
| ユニゾンをわずかにずらす | 矩形波 2 を、矩形波 1 と同じ音の、周期を 1〜4 だけ（低い音域を跳ねる 3 曲目では、周期の 2%）ずらした音にする。2 つの周波数の差で、1 秒に数回のうねりが出る | 全曲の盛り上がる部分。うねりの速さ（中央値）: 1 曲目 7.7、2 曲目 4.8、3 曲目 約 2、ボス 8.6、タイトル 2.4 回／秒 |
| 発音を少し遅らせる | 矩形波 2 を、同じ旋律の 1〜3 フレーム遅れ・小さめの音量にする（ダブリング、コーラス風） | 1 曲目の主旋律、3 曲目の前半 |
| 遅れを大きくする | 9〜15 フレーム遅らせて、やまびこにする | 1 曲目の導入、2 曲目の和音、ボスの和音 |
| 高速アルペジオ | 1 チャンネルで、フレームごとに音程を切り替えて和音に聞かせる | 2 曲目とボスの和音、1 曲目の中間部 |
| デューティ比を毎フレーム動かす | 12.5% → 25% → 50% → 25% と回して、フィルターを開け閉めするような音色の動きを作る | 3 曲目（アシッド）の旋律 |
| オクターブ上の重ね | 矩形波 2 を 1 オクターブ上、1 フレーム遅れで重ねる | 3 曲目の後半 |
| DPCM のドラム | キックとスネア | 全曲 |

| タイトル | アンビエント・テクノ | 112 BPM | A マイナー | 17 秒 | 長い音のユニゾン（ゆっくりしたうねり）、低い三角波、途中から崩したキック |
| SECTOR（一・四・七巡目…） | トランス | 150 BPM | A マイナー | 51 秒（6 秒から） | 16 分のアルペジオの導入 → 主旋律（少し遅らせた重ね）→ 同じ旋律をユニゾンのうねりで → 中間部 → もう一度 |
| SECTOR（二・五・八巡目…） | ドラムンベース | 180 BPM | D マイナー | 24 秒（3 秒から） | DPCM のブレイクビーツ、うねる三角波のベース、和音の刻みとやまびこ → 長い旋律をユニゾンのうねりで |

| ゲームオーバー | アンビエント | 100 BPM | A マイナー | 29 秒（10 秒から） | ゆっくり下がる旋律（ユニゾンのうねり）のあと、低い音を伸ばし続ける。画面が残っている間、鳴り続ける |
| ボス | ハード・テクノ | 164 BPM | C マイナー（♭2 を強調） | 23 秒 | **導入なし**で、最初から旋律（ユニゾンのうねり）。16 分で刻む三角波、毎拍のキック。続いて減七の和音の刻み、旋律、最後に 2 音の警報。ボスは 10 秒ほどで終わるので、聞かせどころを先頭に置いた（著者の指摘、2026-10-11） |

- どの曲も、ベースは三角波で、キックの無い拍の隙間を埋める。SECTOR の 3 曲とボスは、全小節の 8 割以上にキックがある（検査している）
- **切り替え**: タイトル → 開始で SECTOR の曲、大ボスの区間（一巡の 10 区間目）でボスの曲、倒すと SECTOR の曲に戻る。中ボス（5 区間目）では曲を替えず、SECTOR の曲がそのまま続く（著者の決定、2026-10-11。中ボス専用の曲が無いため）。周回が変わると次の曲になる。ゲームオーバーでは専用の曲になる。
  切り替わった曲は頭から始まる。**切り替えは、鳴っている曲の次の拍に合わせる**（最大で 3 分の 1 秒ほど待つ）ので、リズムがつまずかない
- 消音中、BGM を切っているとき、画面が隠れているときは鳴らない。戻ると、そのとき鳴るべき曲が頭から 1 回だけ始まる
- 測った音量（最大）: 曲だけで 0.31〜0.40（−10〜−8 dBFS）。効果音より小さくしてある

### 効果音を曲に合わせる（2026-10-11）

著者の指摘「ロック音はポップすぎて、いまの BGM に合わない」を受けて、音程のある効果音を見直した。

- **ロック**: 上へしゃくる音（880→1320 Hz）をやめ、1 つの高さの、短く乾いた音にした。照準が合う音で、鳴き声ではないように
- **レーザーを放つ**: 0.2 秒かけて下がる音を、0.11 秒の短く鋭い下降にした
- **曲の調に合わせて移す**: 音程のある効果音（ロック、編隊の全滅、島の全滅、区間が変わる、エクステンド、開始、連鎖が切れる）は A を基準に書き、鳴っている曲の調へ移して鳴らす（トランスは A、ドラムンベースは D、アシッドは E、ボスは C）。
  これまでは、どの曲の上でも同じ高さで、C メジャーの和音を含んでいたので、短調の曲とぶつかっていた
- **長調の響きを抜く**: 島の全滅はド・ミ・ソだったのを、根音・5 度・オクターブにした。エクステンドは長調の分散和音だったのを、5 音の短音階にした
- **上がり方**: ロックの数と連鎖は、半音ずつではなく、5 音の短音階を 1 つずつ上がる。どの段も、曲の調の音になる
- 音程の無い音（ショット、命中、撃破、ミス、かすり）は変えていない。ゲームオーバーのジングルは、曲が止まったあとに鳴るので移さない

### 聞いてもらって直したこと

- 2026-10-11「タイトルの、メロディではない音の音色が変」: 三角波の作り方の誤りだった。32 段の階段波の倍音を、1 段につき 1 点だけで測っていたので、31 番目と 33 番目の倍音が基音と同じ大きさで入り、低音が「ブー」という濁った音になっていた（55 Hz の低音に、1.7 kHz と 1.8 kHz が同じ強さで乗る）。
  段を細かく測るように直し、その 2 つは基音の 3% になった。全曲のベースに効く。検査を足した（`test/music.test.mjs`）。直したあと曲全体が小さくなったので、BGM の音量を 0.26 から 0.34 に上げた

- 同日「ベースの音はまだおかしい。音量が減っただけ」「ハイハットとキックは問題ないが、少し小さい」: 上の修正のあと、三角波だけを合成して測り、波形そのものは正しい三角波になっていることを確かめた。残る原因として 2 つを直した。
  - **音の出だしと終わりの「プツッ」**: 三角波を、音ごとに音量 0 と最大の間で瞬時に切り替えていた。実機の三角波は「その場で止まり、そこから再開する」ので段差が出ないが、こちらは毎回、波の途中から鳴り始めて途中で切れ、音ごとにクリックが入っていた。出だしと終わりを 4 ミリ秒かけて開け閉めするようにした
  - **低すぎる音域**: タイトルのベースは 41〜55 Hz、1 曲目も 44〜55 Hz だった。この高さでは基音がほとんど聞こえず、階段波に特有の高い倍音（基音の 31・33 倍）のほうが耳に付く。ベースを 1 オクターブ上げ、全曲で c2（65 Hz）より下を使わないことにした（検査を足した）
  - ハイハットとキック: ノイズを 0.14 から 0.2 に、DPCM を 0.24 から 0.34 に上げた
  - **どちらが原因だったかは、聞いて確かめていない**

### 確かめていないこと

- **耳で聞いていない。** 検査しているのは、データが制約を守っていること、うねりの速さ、無音や音割れが無いこと、切り替えの動きである。旋律として良いか、疾走感があるか、音量の釣り合いが良いかは、聞いてもらう必要がある
- DPCM のドラムは、差分で追った波形を計算で作ったもので、実機のサンプルではない
- 矩形波は、倍音を 48 個までで打ち切った波形である（高い音での折り返しを避けるため）

## 仕組み

```
シミュレーションの出来事（sim.events）→ バス（src/audio/bus.js）→ キット（src/audio/kit.js）→ 再生部（src/audio/webaudio.js）
```

- シミュレーションは音を知らない。出来事の一覧を出すだけで、音を変えても状態ハッシュは変わらない
- キットは音をデータとして持つ。バスは、何を鳴らしてよいかを決め、決めたことを記録する（`window.__game.audio.log`）
- 即座に再生するリプレイ（`runReplay`）は無音である

## 検査

| 検査 | 中身 |
| --- | --- |
| `test/audio.test.mjs` | シミュレーションが出す出来事がすべてキットに載っていること（音か、理由つきの「なし」）、長さと声の枠、同じ声の音が重ならないこと、最大音量の合計、同じフレームの衝突・優先度・消音・画面が隠れたときの扱い、実際のプレイ 1 分で 1 つの声に 1 フレーム 2 音が始まらないこと |

| `node tools/check-shell.mjs` | キーを押すまで出力が開かないこと、開始の音とショットの音が出力へ送られること、消音 |

## 確かめていないこと

- **人の耳で聴いていない。** 音色、音量の釣り合い、うるささは、どれも未確認である。ショットの音が 1 秒に 20 回鳴り続けて耳障りでないかは、特に確かめたい
- スマートフォンでの発音、ゲームパッドだけで始めたときの発音
